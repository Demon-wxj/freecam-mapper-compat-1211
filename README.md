# Freecam 与 MapperPlugin 兼容

协调 Freecam 和 MapperPlugin 的相机状态，减少两者同时使用时的冲突。

Minecraft **1.21.1 / Fabric / Java 21**。源码版本 `1.0.1-mc1.21.1`，Mod ID：`freecam_mapper_compat`。仅客户端使用。

将本扩展与 Freecam `1.3.0+mc1.21`、MapperPlugin `1.4.4-fabric+1.21` 一起装入客户端，仍按原模组的方式操作相机。
